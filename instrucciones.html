📋 Guía de uso

Instrucciones

Todo lo que necesitás saber para cargar pedidos de forma correcta y evitar errores.

🔓
1. La cuenta debe estar pública

Este es el requisito más importante. La cuenta de Instagram del cliente debe estar configurada como pública durante todo el proceso de envío del pedido.

⚠️ Si la cuenta está en modo privado, el pedido puede fallar o demorarse indefinidamente. Asegurate de verificarlo con el cliente antes de enviar el pedido.
🚫 No procesamos devoluciones por pedidos fallados a causa de cuentas privadas.

¿Cómo hacerlo público? Instagram → Ajustes → Privacidad → Cuenta privada → Desactivar.

👤
2. Cómo copiar el link del perfil

Si el pedido es de seguidores, necesitás el link directo al perfil de la cuenta.

  • 1 Abrí Instagram y visitá el perfil del cliente.
  • 2 Tocá los 3 puntos (⋮) en la esquina superior derecha del perfil.
  • 3 Seleccioná "Copiar link del perfil".
  • 4 Pegá el link en el campo correspondiente del formulario.
Ejemplo de link correcto
https://www.instagram.com/nombreusuario/
💡 También podés escribirlo manualmente: instagram.com/nombreusuario. Asegurate de que el usuario sea el correcto.
📸
3. Cómo copiar el link de una publicación

Si el pedido es de likes, necesitás el link específico de la publicación que quiera impulsar.

  • 1 Abrí la publicación en Instagram (foto, reel o video).
  • 2 Tocá los 3 puntos (⋮) arriba a la derecha de la publicación.
  • 3 Seleccioná "Copiar link".
  • 4 Pegá el link en el campo del formulario.
Ejemplo de link de publicación
https://www.instagram.com/p/CXaBCDE12fg/
⚠️ El link de la publicación debe ser público. Si la publicación está archivada o la cuenta es privada, el pedido fallará.
🚀
4. Cómo cargar un pedido correctamente

Seguí estos pasos cada vez que cargues un pedido nuevo:

  • 1Desde el panel, tocá "Recargar / Nuevo pedido".
  • 2Seleccioná la red social (actualmente solo Instagram).
  • 3Elegí el servicio: Seguidores o Likes.
  • 4Ingresá el nombre del solicitante (puede ser el nombre del cliente o el tuyo).
  • 5Escribí la cantidad deseada. El precio se calcula automáticamente.
  • 6Pegá el link correcto según el servicio elegido.
  • 7Subí la imagen del comprobante de pago.
  • 8Revisá los datos en la sección "Revisar solicitud".
  • 9Tocá "Enviar por WhatsApp" para confirmar el pedido.
⚙️
5. Cómo elegir servicio, cantidad y revisar datos

Servicio: usá los botones de selección para elegir entre Seguidores o Likes. Según lo que elijas, el campo de link cambia automáticamente.

Cantidad: podés ingresar cualquier número. El precio se actualiza automáticamente al escribir.

Cálculo de precios
Seguidores: cada 100 = $500 ARS
Likes: cada 100 = $300 ARS

Antes de enviar, revisá siempre la sección "Revisar solicitud" al final del formulario. Muestra todos los datos ingresados para que puedas confirmarlos antes de enviar.

⏱️
6. Tiempo de procesamiento

Los pedidos pueden demorar entre 10 y 20 minutos en completarse desde que son aprobados por el equipo de UPSTORE.

💡 El cliente puede empezar a ver los resultados progresivamente dentro de ese lapso. No es necesario hacer nada más después de enviar el pedido.

Si después de 30 minutos el pedido no está completo, contactá soporte con el ID del pedido.

🔍
7. Verificá bien el usuario o link antes de enviar

Este paso es muy importante. Una vez enviado el pedido, no se puede modificar ni redirigir a otra cuenta o publicación.

  • ✓Confirmá con el cliente que el link que te pasó es el correcto.
  • ✓Abrí el link en el navegador antes de pegarlo para verificar que carga bien.
  • ✓Asegurate que el nombre de usuario no tenga errores de tipeo.
  • ✓Revisá la sección "Revisar solicitud" antes de enviar.
🚫 UPSTORE no se responsabiliza por pedidos enviados a perfiles o publicaciones incorrectas por error del revendedor.
🔒
8. Cuentas privadas — riesgo de falla

Si la cuenta del cliente está en modo privado al momento de procesar el pedido, el sistema no podrá acceder al perfil y el pedido puede fallar o demorarse significativamente.

¿Qué hacer?

  • 1Antes de enviar, pedile al cliente que ponga su cuenta en público.
  • 2Indicale que la mantenga pública hasta recibir una confirmación de que el pedido está completo.
  • 3Una vez completado el pedido (10-20 min), puede volver a privada si lo desea.
⚠️ Este requerimiento aplica también para Likes en publicaciones de cuentas privadas.
📌
Resumen rápido
  • ✓Cuenta pública antes y durante el pedido.
  • ✓Verificar link/usuario antes de enviar.
  • ✓Subir comprobante de pago (obligatorio).
  • ✓Revisar datos en "Revisar solicitud".
  • ✓Tiempo de entrega: 10 a 20 minutos.
  • ✓Ante cualquier inconveniente, contactar con el ID del pedido.
